# Glass bottle body: mold seam identification (superseded v1.0)

Superseded by version 3.0. This version is kept for audit only.

## Expected feature (old fixture)
In the old fixture, the mold seam was at normalized x 0.30 to 0.36, because bottles were loaded off-centre. A centre-line line was treated as suspicious.
