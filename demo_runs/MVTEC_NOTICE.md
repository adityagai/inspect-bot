# MVTec AD images in M1–M5

`demo_runs/M1` to `M5` contain images from the MVTec Anomaly Detection dataset: one test image and one approved `train/good` reference each.

- **Source:** Paul Bergmann, Kilian Batzner, Michael Fauser, David Sattlegger, Carsten Steger. *The MVTec Anomaly Detection Dataset: A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection.* IJCV 129, 1038–1059 (2021); and CVPR 2019.
- **License:** [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Use is non-commercial only. These images are redistributed unchanged under the same license for this academic project.

The full dataset is not included. Download it from https://www.mvtec.com/company/research/datasets/mvtec-ad.
